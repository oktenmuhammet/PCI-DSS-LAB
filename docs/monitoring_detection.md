# Monitoring & Detection

## Overview

One of the primary goals of this PCI DSS Lab was not only to deploy security technologies, but also to validate the ability to detect suspicious and unauthorized activity across the environment.

A centralized monitoring architecture was implemented using Wazuh SIEM to collect, correlate, and analyze security events generated by systems located in different security zones.

The monitoring environment was designed from a Security Operations Center (SOC) perspective, focusing on visibility, detection, and incident identification.

---

# Monitoring Architecture

All systems within the lab are connected to Wazuh through agents.

Monitored Systems:

* Active Directory Server
* Windows Server 2016
* Windows 10 Clients
* Linux Servers
* Web Server
* Application Server
* Database Server
* HashiCorp Vault
* OpenLDAP
* Jump Server
* Backup Server

All collected events are centralized within Wazuh for analysis and alert generation.

---

# Wazuh SIEM

Wazuh serves as the central monitoring platform.

Core Functions:

* Log Collection
* Security Event Analysis
* Alert Generation
* File Integrity Monitoring
* Active Response
* Compliance Visibility

The platform provides centralized visibility across the entire environment.

---

# File Integrity Monitoring (FIM)

File Integrity Monitoring was enabled on critical systems.

The objective was to detect unauthorized modifications to sensitive operating system files.

Monitored Examples:

* /etc/passwd
* /etc/shadow
* Critical configuration files
* Security-related system files

Detected Events:

* File modification
* File deletion
* File creation
* Permission changes
* Checksum changes

Alerts are automatically generated when unauthorized modifications occur.

---

# LDAP Monitoring

OpenLDAP events are monitored through Wazuh.

The environment tracks directory-related activities such as:

* User creation
* User deletion
* Group modifications
* Privilege changes
* Authentication activity

Example Detection:

Creation of a new LDAP user generates a security event that becomes visible within the SIEM dashboard.

This provides visibility into identity-related changes.

---

# Vault Monitoring

HashiCorp Vault events are integrated into the monitoring platform.

Monitored Activities:

* Authentication attempts
* Failed logins
* Unauthorized access attempts
* Secret access requests
* Policy violations

Example Detection:

Unauthorized access attempts against Vault generate alerts for investigation.

This helps protect encryption keys and sensitive secrets stored within the environment.

---

# Jump Server Monitoring

Administrative access is monitored through Jump Server.

Monitored Activities:

* Login attempts
* Privileged sessions
* Command execution
* File transfers
* Administrative actions

This visibility allows tracking of privileged user behavior and administrative activities.

---

# Root Activity Detection

Linux systems are monitored for privileged activity.

Examples:

* sudo execution
* privilege escalation attempts
* root account activity
* sensitive command execution

Administrative actions can be correlated with other security events for investigation purposes.

---

# Malware Monitoring

Endpoint protection solutions generate security events that are forwarded to Wazuh.

Linux Systems:

* ClamAV

Windows Systems:

* Microsoft Defender

Detected Events:

* Malware detections
* Scan results
* Security warnings
* Suspicious file activity

---

# Web Application Monitoring

Security events generated by the web application infrastructure are monitored.

Components:

* Nginx
* Reverse Proxy
* ModSecurity WAF

Monitored Activities:

* Blocked requests
* Suspicious requests
* Web attacks
* Policy violations

This visibility helps identify potential attacks targeting the payment application.

---

# Alerting Capabilities

The monitoring platform generates alerts for critical security events.

Examples:

* Unauthorized Vault access
* LDAP modifications
* Privileged activity
* Malware detections
* File integrity violations
* Authentication failures

Alerts are presented through the Wazuh dashboard for investigation and response.
